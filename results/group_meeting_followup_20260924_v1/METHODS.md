# 实际方法、数据与读数

## 共同设置

BERT-base；SST-2 二分类、AG_NEWS 四分类；50 个客户端各 256 条，共 12,800 条训练样本，每轮参与十个客户端。LoRA 使用 Q/V 投影、rank 16，客户端标签比例按 Dirichlet α=0.3 划分，学习率 0.001、本地 batch 16、每次参与训练一个 epoch。五个 seed 为 7、13、21、42、87。

全局准确率评价分别使用 SST-2 的 872 条和 AG_NEWS 的 7,600 条验证样本。主端点先在每个 seed 内取第 26–30 轮均值；百轮实验另取第 96–100 轮，再跨 seed 等权平均。配对区间是五 seed、df=4 的描述性 95% t 区间。该系列是既有 benchmark 上的机制探索，seed 7/13 参与过早期学习率开发；独立单位仍是五个 seed。

## 方法编号

| 代码标记 | 含义 |
|---|---|
| `pcla` / `L2_pcla_r100` | 归一化评分与历史状态选择层及层内组件，按轮交替更新 A/B |
| `replay_random_rank` | 沿用相应 PCLA 的层与每层数量，随机替换具体组件编号后独立训练 |
| `full_alt` / `L1` | 所有层和 rank 都更新，A/B 按轮交替 |
| `L3` / `fed_both_mean` | 每个客户端同时训练完整 A/B，服务器分别平均 |
| `fed_both_exact` | 同时训练 A/B，并将普通因子平均与乘积平均的差额补入基础权重 |
| `fed_ffa_b` | A 固定，只训练 B |
| `T1` | 完整交替 LoRA，服务器只施加平均增量的 0.5 倍 |
| `T2` | 完整交替 LoRA，按训练正类比例把客户端排序分十组，每轮每组随机抽一人 |
| `V1` | 双因子精确聚合后重拆分 LoRA 部分 |
| `V2` | 完整交替 LoRA 后重拆分 |
| `V3` | 以预训练 Q/V 权重的右奇异方向构造冻结 A，只训练 B |
| `V4_pcla_svd` | PCLA 后逐轮 SVD 重拆分，含零奇异方向的处理 |
| `V5_replay_svd` | 相同重拆分，使用对应 V4 的层与数量，随机选 rank |
| `central_pcla` | 单模型集中式组件选择；每轮 160 步、A/B 交替，轮首重建 AdamW |
| `central_replay_random_rank` | 同一集中式设置，保持对应 PCLA 的每层配额、随机选编号 |
| `central_random_rank` | 同时随机选择层及编号 |
| `central_full_alt` | 同一集中式设置，更新全部组件 |
| `R_*_normal` | 适配后的上游 FedIT 式普通因子平均 |
| `R_*_ours` | 上游 FedEx 代码保留残差转置 |
| `R_*_ours_fixed` | 同一上游版本，仅去掉残差转置 |
| `R_*_ffa` | 上游冻结 A 的版本 |

`D_agnews_` 前缀表示在 AG_NEWS 上运行。`R_iid_` 与 `R_noniid_` 是同一份样本的均匀打散和原标签偏斜客户端划分。开源对照运行于 A100，其他科学端点运行于 4090；上游对照的 AMP 和本地学习率调度单独记录。

聚合诊断的原始表还沿用当时的作业名，读法如下：

| 作业名或后缀 | 在实验里做什么 |
|---|---|
| `old_pcla` / `old_replay_random_rank` / `old_random` / `old_full_alt` | 前期共享分母的 PCLA、同层随机编号、随机组件与完整交替 LoRA 轨迹；这里的 `old` 只用于区分后续聚合干预。 |
| `trace_*_contributors` | 保持前期记录的层和组件选择序列，只把该位置的聚合分母换成实际更新它的客户端。 |
| `trace_*_function_norm_matched` | 保持同一选择序列，把共享分母产生的有效权重更新整体放大到与贡献者分母更新的范数相近，用于区分分母规则与更新幅度。 |
| `online_pcla_contributors` / `online_replay_contributors` | 在贡献者分母下重新在线训练 PCLA，以及沿用 PCLA 层和数量的随机编号对照。 |
| `central_pooled_both` | 每轮把参与客户端样本合并打乱，单模型同时训练 A/B，优化器跨轮保留。 |
| `central_serial_both` / `central_serial_alt` | 按客户端样本块依次训练，块间重建优化器；分别同时更新 A/B 或按轮交替。 |
| `central_iid_both` / `fed_ffa_b` | 补充批次：每轮从全部训练样本均匀抽样的集中式训练，以及冻结 A、只训练 B 的联邦对照。 |

分母规则的执行标记 F 表示除以本轮全部参与客户端样本量；C 表示只除以该位置的贡献者样本量；G 表示把 F 的更新范数匹配到 C。当前主方法使用 F。[逐 seed 聚合差值](data/aggregation_all_five.json)保留每种规则的配对结果。

## 三种评价对象

**原参数**是每轮实际用于训练的全局适配器。**因子参数 EMA**分别平均 A、B 和分类头，β=0.8，只读评价后恢复训练状态；L2 的 EMA 以第一轮全局参数初始化，并用 float64 累积。**Logits 集成**先将同一样本在末五轮的分类前分数取平均，再分类。

因子 EMA 与有效权重 `sBA` 的 EMA 不同。本轮使用的是前者，能继续用相同 rank 的适配器评价。将两个因子的平均值相乘，一般不等于先相乘后平均，因此三种读数分别保留。

## 本地测试

客户端本地测试来自训练池中原来未分配的样本，按本地正负比例抽取；主表过滤与任何客户端训练样本共享连续四词片段的样本。准确率按五十个客户端等权平均。Balanced accuracy 是两类召回率的平均，只在两类各至少五条的客户端中计算；seed 7/13/21/42/87 分别有 25/19/19/28/22 个符合条件。

`P0` 为多数类基线；`P1` 为共享模型直接评价；`P2` 为共享模型在各客户端再训练一个 epoch；`P3` 为共享 A、客户端私人 B；`P4` 为每个客户端独立训练六个 epoch。`P1/P2` 对应相同测试样本。

这些测试回答的是模型能否适应各客户端的标签分布。共享模型的表示价值可通过 P2 与 P4 比较；P2 与 P1 则说明额外本地适配的收益及类别间取舍。

## SVD 解释

SVD 重拆分按奇异值大小排序，并调整符号约定。它改变参数坐标、尺度和后续训练路径；零方向还需要保持可重新训练的因子。不能把重拆分后准确率变化单独归因于“语义对齐”。

子空间重合度是 `||U_t^T U_(t+1)||_F²/k`。每个 seed 先平均可计算单元，再跨 seed 平均。相同子空间内部仍可旋转或交换方向，所以子空间稳定不等于各个编号跨轮一一稳定。

## 成本与旧实验

PCLA 客户端的组件预算为 48/64/96，完整 LoRA 更新全部 192 个 Q/V 组件，双因子同时训练还改变了可更新因子数。集中式三种部分更新方法的统一预算为 64。完整模型对照展示质量参照，同预算选位贡献由各自的 replay 比较回答。

旧 pooled LoRA 跨轮保持优化器；新的集中式组件组轮首重置。它们分别证明基本学习能力，不能直接用两组数字相减归因于组件选择。聚合诊断的补充批次（执行标记 S1）中，IID 集中式 seed 13 从第 21 轮起逐轮仅预测一个类别；五 seed 均值 80.79% 已连同该 seed 保留在[逐 seed 原表](data/s1/S1_PER_SEED_ENDPOINTS.csv)。

[完整可得逐轮记录](data/curves/README.md)逐项区分原参数、训练时的因子 EMA 和已有轨迹上的只读 EMA 补算；没有全局逐轮轨迹的本地终点作业单列在覆盖表中。[成本记录](data/costs/COSTS_README.md)分开报告同实现 4090 的时间与 A100 上游实现的时间；服务器 SVD 和额外 EMA 评价未单独计时。实际执行源码、配置、冻结队列和相对原仓库基线的逐文件 SHA/diff 见[源码索引](reproduce/executed_sources/SOURCE_README.md)。

## 1. 主线

> PEFT 的参数预算（LoRA 的秩）应该随客户端的资源而变。但秩不只决定容量，还决定优化动态：在 Adam 下，只训练 r 个组件的客户端，每一步的函数变化只有完整训练的约 r/R。本文提出一个联邦 LoRA 算法，用 R/r 放大补偿这种动态差异，并按组件的覆盖程度选择聚合方式。它让只训练、只上传 r/R 组件的弱客户端达到完整本地训练的精度。

题目中每个词的落点：

| 词 | 落点 |
|---|---|
| Parameter-Efficient Fine-Tuning | rank-R LoRA 看作 R 个 rank-1 组件 b_k a_kᵀ；秩就是每个客户端的参数预算 |
| Adaptive | 两层自适应：① 每个客户端的秩 r_i 按资源设定，放大因子 α_i = R/r_i 随之确定；② 聚合方式按组件的覆盖程度确定 |
| Federated | 一个方法 = 分配 + 本地训练规则 + 聚合，三者都针对联邦场景设计并分别检验 |
| Large Models | Qwen2.5-0.5B 解码器（R = 64）上完整复现；RoBERTa-base（R = 8）作为可控的机制试验台 |

与 PEFT 文献的连接点：**秩相关的缩放**。LoRA 用 α/r，rsLoRA 证明大秩时应该用 α/√r。本文处理的是同一个问题在联邦场景中的版本：同一个适配器里，不同客户端训练的组件数不同，缩放必须按客户端补偿。

## 3. 贡献（第 1 章末尾的列表）

1. **找出异构秩联邦 LoRA 中弱客户端精度损失的来源。** 损失来自受限的本地训练动态，而不是通信：在 RoBERTa 上，完整训练但只上传 2/8 组件（vref 80.17）就等于同构 r8（80.19），受限训练（L2）则掉到 77.85，并反复振荡。
2. **提出放大的受限本地训练，并从 Adam 的尺度不变性推导出放大因子 R/r。** 前向中只放大本轮增量，上传未放大的增量。两个模型上都达到完整本地训练的精度：RoBERTa 上 80.12 vs 80.17；Qwen 上 80.41 vs 80.48。
3. **提出按覆盖选择的聚合，并给出收缩推导。** 每个组件有多个弱贡献者时用 Hájek，约一个时用收缩。同一套本地规则下，两个模型上的最优聚合方式正好相反（RoBERTa 上 Hájek +2.62；Qwen 上收缩 +2.28），与推导的预测一致。
4. **系统的消融和比较。** 覆盖 α、分配、聚合、梯度路径、状态草图，以及 Fed-PLoRA、FLASC、FSLoRA 三类已有方法；在混合秩 {1,2,4}、r = 1、20% 强客户端下稳健。

## 4. 章节

### 第 1 章 引言

1. 联邦微调大模型：数据不出本地，PEFT 让通信和存储可负担。
2. 客户端资源不同，PEFT 预算应当按客户端调整。已有工作（HetLoRA、FlexLoRA、Fed-PLoRA、FSLoRA）都让弱客户端只训练和上传一部分组件。
3. **资源动机写成带宽和存储**：每轮上传量和 LoRA 训练状态都严格等于 r/R。Qwen2.5-0.5B、R = 64、r = 8 时，上传从 134 MiB 降到 17 MiB（[resource_case §2](../designs/resource_case_2026-10-18.md)）。
4. 核心问题：这样做的精度代价从何而来，怎样消除？
5. 贡献列表（§3），章节导读。

### 第 2 章 背景与相关工作

1. LoRA 与秩：α/r 缩放、rsLoRA 的 α/√r、秩作为预算。
2. Adam 的尺度不变性：每一步的参数位移由学习率决定，与梯度的大小无关。这是第 4 章推导的基础。
3. 联邦学习：FedAvg、部分参与；Horvitz–Thompson / Hájek 加权（按包含概率修正）。
4. 异构秩联邦 LoRA，按"分配 / 本地规则 / 聚合"三个维度归类：
   - HetLoRA、FlexLoRA：截断或 SVD 重分配；
   - Fed-PLoRA：随机选组件，未选组件冻结在前向中，拥有者平均，不放大；
   - FLASC：完整训练，稀疏上传；
   - FSLoRA：随机草图，前向放大 R/r（来自无偏性），零填充平均；
   - raFLoRA 等。
5. 本文的位置：把三个维度解耦，分别推导和检验。

### 第 3 章 问题建模与诊断

1. **组件视角的形式化。**
   - ΔW = Σ_k b_k a_kᵀ，k = 1…R；
   - 客户端 i 分配到集合 S_i，|S_i| = r_i；
   - 每轮：分配 → 本地训练 → 上传 S_i 上的增量 → 按组件聚合。
2. **诊断一：通信不是瓶颈。**
   - RoBERTa、3 个 seed 的后期核心弱端准确率：vref 80.17 ≈ r8 80.19；L2 77.85。
   - 轮间波动：L2 2.69，r8 0.34。
   - 出处：[research_two_directions §7](../designs/research_two_directions_2026-10-17.md)。
3. **诊断二：服务器端的标量修正不够。** 在线 RCS 77.64，固定收缩 78.32（只追回 25% 的差距），弱端学习率 × 0.6 为 75.77。由此得出：修正必须作用在本地训练上。出处：同上 §4。
4. **诊断三：单步探针定位机制。**
   - 受限训练的分类头沿共识方向的步长是 r8 的 1.61–1.91 倍；
   - 换上完整训练的头部，差距从 −3.83 缩小到 −1.24；
   - 冻结头部时，压力转移到 LoRA（步长 2.27–2.49 倍）。
   - 出处：D2 / D3，§5–§6。
5. 小结：受限训练每一步推进不足，本地的其他参数会去补偿；跨客户端拼接后，这种补偿就变成了过冲。

### 第 4 章 方法

1. **算法总览**（算法框 + 图 4.1 框架图）。
2. **覆盖均衡分配。**
   - 每个组件的弱端包含概率均为 r_i/R，保证每个组件都有贡献者；
   - 消融：改用前缀分配 −1.55。
3. **放大的受限本地训练（核心）。**
   - 前向：B₀A₀ + α(BA − B₀A₀)，α = R/r_i；放大的那一项不回传梯度，上传未放大的增量。
   - 引理（Adam 第一步的尺度不变性）与命题：一阶降损对被训练的组件数可加，所以放大 R/r 能让本地函数变化的速度与完整训练一致。
   - 为什么只放大增量：本地起点就是全局模型，状态不受草图误差 ξ_S 影响。
   - 为什么放大在前向而不在学习率：两者只在一阶相同，实测前向放大高 0.76。
   - 出处：[algorithm_design_2026-10-18_amplified_restricted §4–§7](../designs/algorithm_design_2026-10-18_amplified_restricted.md)。
4. **按覆盖选择的聚合**（新写的推导）。
   - 组件 k 的聚合可以统一写成 c_k · ĝ_k，其中 ĝ_k 是该组件 n_k 个贡献者的平均。Hájek 对应 c_k = 1。零填充对应 c_k = ρ_k，ρ_k 是贡献者的权重份额（`scra/core.py` 中 `block_aggregates`：零填充 = 拥有者平均 × ρ_k）。
   - 均方误差：MSE(c) = (1 − c)²‖g_k‖² + c²σ²/n_k，最优 c* = n_k·SNR / (1 + n_k·SNR)。贡献者越少，最优的一步越小。
   - 规则：m = 每轮弱参与者数 × r/R。m ≥ 2 时用 Hájek，m ≈ 1 时用收缩。
   - 两个设定的取值：每轮 10 个参与者，约 1 强 9 弱。
     - RoBERTa：m = 9 × 2/8 = 2.25，ρ ≈ (1 + 2.25)/10 ≈ 0.33；
     - Qwen：m = 9 × 8/64 = 1.125，ρ ≈ (1 + 1.125)/10 ≈ 0.21。
     - Qwen 上把 Hájek 的服务器步长直接设为 0.25，效果与零填充相同（80.92 vs 80.87），与 ρ ≈ 0.21 对得上。写作时用实际的样本权重重算 ρ。
5. **代价分析。**
   - 上传量和 LoRA 状态都是 r/R；
   - 计算量节省 ≤ 8%，峰值显存节省 10–14%（R = 64）；
   - 本方法相对 vref 额外节省的是训练状态。
6. **与已有方法的关系。**
   - FSLoRA：放大因子相同，来源不同（无偏性 vs 优化动态）；
   - Fed-PLoRA：前向结构相同，但不放大，所以在 Qwen 上崩溃；
   - FLASC：完整训练 + 稀疏上传，本方法训练得更少，精度反而更高（+0.79）。

### 第 5 章 实验一：RoBERTa-base（机制试验台）

1. 设定：MNLI，50 个客户端，每轮 10 个；R = 8，r = 2；10% 强客户端；150 轮；3 个 seed；指标为 30 个核心弱客户端在第 110–150 轮的平均准确率。
2. **主结果。** r8 80.19，vref 80.17，**本方法 80.12**，L2 77.85；振荡 0.35（L2 为 2.69）。第 10 轮冷启动时本方法 65.63，r8 65.43。
3. **消融**（单 seed 2040）。

   | 消融 | 相对本方法 |
   |---|---:|
   | α = 2 | −0.58，振荡升到 0.97 |
   | α = 8 | −0.14 |
   | 拥有者平均 | −0.45 |
   | 前缀分配 | −1.55 |

4. **稳健性。** 追回比例：r = 1 为 1.01，混合秩 {1,2,4} 为 0.89，20% 强客户端为 0.92。混合秩时 α_i = R/r_i 直接推广。
5. **分解与比较**（批次 2，3 个 seed 配对）。

   | 比较 | 差值 |
   |---|---:|
   | 只放大增量 vs 对状态做草图 | +0.42 |
   | 前向放大 vs 学习率 × α | +0.76 |
   | Hájek vs 零填充（同一 FSLoRA 前向） | +2.62 |
   | 本方法 vs FSLoRA 风格 | +2.95 |
   | 本方法 vs Fed-PLoRA 风格 | +2.96 |
   | 本方法 vs FLASC 风格 | +0.79 |

### 第 6 章 实验二：Qwen2.5-0.5B（大模型通用性）

1. 设定：
   - MNLI 改为下一个词预测，标签词为 " yes / maybe / no"；
   - 7 类线性层都加 LoRA；R = 64，r = 8；
   - 60 轮，lr 2e-4（阶段 A 按事先规则选出）；3 个 seed；
   - 指标为核心弱端在第 40–60 轮的平均准确率。
2. **不放大就崩溃。** L2 33.70，Fed-PLoRA 风格 33.07（接近随机水平）；本方法稳定训练。
3. **α = R/r 再次最好。** α = 4 时 77.35，振荡 3.51；α = 8 时 78.45；α = 16 和 32 时崩溃（45.18、31.30）。
4. **本方法达到完整本地训练的精度。** 3 个 seed 配对：
   - 本方法（收缩）80.41 vs vref（收缩）80.48，差 −0.07 [−0.34, +0.20]；
   - 本方法（Hájek）78.36 vs vref（Hájek）79.87。
5. **聚合反转。**
   - 收缩对本方法 +2.05 [+1.23, +2.87]，对 FSLoRA 前向 +2.28 [+2.09, +2.47]，对完整训练 +0.61；
   - 分配方式（均衡 vs 随机）没有影响（+0.28）；
   - Hájek + 服务器步长 0.25 = 80.92，与收缩相同。
   - 这三点共同说明：起作用的是收缩的大小，正如 §4.4 的推导所预测。
6. **差距分解。** r8 82.19 → 只上传分配组件 80.48（−1.72）→ 本方法 80.41（−0.07）。本地训练的代价被完全消除，剩下的是部分上传本身的代价。
7. **与 FSLoRA 原版：打平**（80.41 vs 80.21，+0.20）。解释：本地规则在梯度路径一致时等价（+0.15 / −0.08），FSLoRA 的零填充正好落在 Qwen 设定下合适的收缩区间。而在 RoBERTa 上，本方法比它高 2.95。

出处：[c2_1_design §7–§14](../designs/c2_1_design_2026-10-18.md)，`federated_finetuning/runs/c2_fed_20261018/REPORT_C2_1.md`。所有旧版本运行都经过完整 60 轮重放验证，结果逐轮完全一致。

### 第 7 章 讨论与展望

1. 两条设计原则的一般意义：
   - 秩相关的补偿：任何"只训练部分 PEFT 参数"的联邦方法都需要它；
   - 聚合的收缩应随覆盖程度变化。
2. 展望（一段即可）：
   - 让服务器根据客户端之间的分歧在线估计 c_k，得到连续自适应的聚合；
   - 更大规模的模型（1.5B–7B）和更多任务；
   - 降低部分上传本身的代价（Qwen 上 1.72pp）。
3. 结论。

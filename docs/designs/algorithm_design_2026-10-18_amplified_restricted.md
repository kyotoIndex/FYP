## 0. 一句话与结论先行

> 在异构 rank 联邦 LoRA 中（强端稀缺，弱端只能训练 R 个 rank-1 分量中的 r 个），我们修改的基线是"覆盖均衡分配 + Hájek 聚合的受限训练"。修改方式是：在弱端的本地前向中，把被训练分量的**本轮增量**放大 α = R/r 倍，梯度只经过未放大的项，上传未放大的增量。这样做的理由是：在 Adam 下，每一步的一阶降损对被训练的分量数是可加的。只要各分量在一阶意义下可以互换，放大 R/r 就能让弱端本地的函数变化速度与完整训练一致，残差就不会再被分类头和被训练分量"补偿"。正是这种补偿，经过服务器的拼接后变成了过冲。

| 组件 | 由哪一步推导得出 | 去掉它的已测后果 |
|---|---|---|
| 前向中放大本轮增量，α_i = R/r_i | §4.2、§6：消除本地降损的缺口 | α = 2：−0.58pp，波动 0.97 [批量] |
| 只放大增量，不对状态做 sketch | §7.1：本地起点就是全局模型 | 换成 FSLoRA 式前向（梯度路径相同）：−0.42pp（3 seed 同向）[批量2 A1a] |
| 放大放在前向里，而不是学习率上 | §7.2：两者只在一阶相同 | 换成"学习率 × α + 服务器 ÷ α"：−0.76pp（3 seed 同向）[批量2 A2] |
| 梯度只经过未放大的项（detach） | §6.4：Adam 下与真实梯度方向相同；在 SGD 下仍是增益 α；梯度裁剪的尺度不变 | 在 FSLoRA 式前向上，改用真实梯度只差 −0.11pp（不显著）[批量2 A1b]；在 Adam 下实际影响很小 |
| 上传未放大的增量 | §5.2：放大后，单个分量的原始增量就处在完整训练的尺度上 | 没有单独消融；按推导，上传放大后的增量会使全局更新过冲 α 倍 |
| 覆盖均衡分配 | §8.1：正性（每个分量都有弱端贡献者），且包含概率均匀为 r_i/R | 前缀分配：−1.55pp [批量] |
| Hájek 聚合（包含概率 r_i/R） | §8.2：恢复强端与弱端的总体比例 | 拥有者平均：−0.45pp（单 seed）[批量]；在 FSLoRA 式前向上换成零填充平均：−2.62pp（3 seed）[批量2 A1c] |
| 分类头：照常训练，按样本数平均，**不加任何头部专用的修正** | §4.3–§4.5：头部过冲是 LoRA 降损缺口的结果，不是独立的原因 | 冻结头部：LoRA 过冲升到 2.3–2.5 倍 [D3] |

## 1. Design Context

**设定**（全部来自 [配置]）：
- 模型与数据：RoBERTa-base，MNLI，50 个按 genre 划分的客户端（seed2026 划分），冷启动，共 150 轮，每轮 10 个客户端。
- 本地训练：每端 20 步，batch 8。每轮新建 AdamW：lr 2e-4，betas (0.9, 0.999)，eps 1e-8，**weight_decay 0**，梯度裁剪 1.0。
- LoRA：放在 12 层的 Q、V 上（共 J = 24 个适配器），R = 8，每个分量的乘子 s = 2。A 用 Kaiming 均匀初始化，B 初始化为 0。分类头从零开始训练，所有客户端都训练它。
- 强端：10%，即客户端 10、11、12、40、41。核心弱端是固定的 30 个客户端。指标是核心弱端第 110–150 轮的平均准确率。

**走到这一步的诊断链：**
1. vref（弱端完整训练、只上传 2/8、Hájek）与全员 r8 一致：80.15 对 80.13 [判别]。budget8（只上传 1/8）为 80.00 [判别]。**差距不在通信，在受限训练本身。**
2. 服务器端标量修正失败：RCS 在线估计追回 −3%，固定收缩 0.63 追回 25%，弱端学习率 × 0.6 追回 −80% [判别]。
3. D2 定位：受限更新的头部和 LoRA 都沿 r8 方向过冲 [D2]。
4. D3：放大前向在一步中追平 vref [D3]。
5. 批量验证：150 轮、3 个 seed 追平 vref / r8，消融和稳健性检验全部通过 [批量]。
6. 文献核对：部分已有先例，最接近的是 FSLoRA [文献 §0]。
7. 批量 2 定位对照：不对状态做 sketch +0.42pp；零填充在 Adam 下 −2.62pp；前向放大比调学习率高 0.76pp [批量2]。

**设计模式：** method（主）+ theory（一阶推导）。相对 SCRA 是一次 revision：SCRA 的分配与聚合保留下来，本地训练被替换。

## 2. Target Claim（FYP 级别）

> 在强端稀缺的异构 rank 联邦 LoRA 中，弱端受限训练造成的精度差距来自本地训练动力学，而不是通信。在 Adam 下，只训练 R 个分量中的 r 个时，每步的一阶降损约降为 r/R。缺口由共同训练的分类头和被训练分量以更大的位移补上，服务器拼接之后，这些补偿沿共识方向叠加成过冲。把被训练分量的本轮增量在本地前向中放大 R/r 倍，冻结分量以当前全局值留在前向，再上传原始增量、做覆盖均衡的 Hájek 聚合，就能消除这个缺口。在 RoBERTa-base / MNLI 上，这一做法追平了弱端完整训练的参照（3 seed：80.12 ± 0.14 对 80.17 ± 0.12）[批量]。

**外部定位**（统一的 AdamW 协议，3 seed 配对 [批量2]）：amp 比 FSLoRA 式高 +2.95pp，比 Fed-PLoRA 式高 +2.96pp，比 FLASC 式高 +0.79pp。这些比较同时改变了多个因素，**只作定位，不作机制证据**。

**本稿不声称：**
- 放大因子 R/r 本身、冻结分量留在前向、"只放大偏离锚点的部分"这一代数形式是新的。它们分别已在 FSLoRA、Fed-PLoRA、Mixout 中出现 [文献 §5]。
- 无偏性或收敛保证。
- 等价于完整训练：单个客户端的位移余弦是 0.992–0.997，不是逐位相同 [D3，research_two_directions §6 核查]。
- 在 RoBERTa 规模下节省显存：峰值显存 1558 对 1557 MiB [批量]。
- 在没有分类头的解码器模型上，或在 SGD 下也成立。两者都没有测过，见 §10 的待测行。

## 3. Problem Formulation

### 3.1 参数化

每个适配器 j ∈ {1, …, J} 的权重是

  W_j = W⁰_j + s · Σ_{k=1}^{R} b_{jk} a_{jkᵀ}

W⁰_j 是冻结的预训练权重。第 k 个 rank-1 分量是 θ_{jk} = (b_{jk} ∈ ℝ^{d_out}, a_{jk} ∈ ℝ^{d_in})，代码中称为一个"块" [代码 core.py]。分类头参数记为 θ_h。可训练参数为 θ = ({θ_{jk}}, θ_h)。

### 3.2 联邦目标

  min_θ F(θ) = Σ_i p_i F_i(θ)，其中 p_i ∝ n_i（样本数），F_i 为客户端 i 的交叉熵

第 t 轮：服务器抽取 10 个参与者 P_t，广播全局值 θ̄ = (b̄, ā, θ̄_h)，客户端训练 T = 20 步后上传位移，服务器聚合。

### 3.3 受限训练的约束

- **强端**（i ∈ 𝒮）：训练全部 R 个分量和头部。
- **弱端**（i ∈ 𝒲）：对每个适配器 j，服务器分给它一个集合 S_i^j ⊂ {1..R}，|S_i^j| = r_i < R。弱端只训练 {θ_{jk} : k ∈ S_i^j} 和头部。
- **未分到的分量**保持本轮的全局值 b̄_{jk}、ā_{jk}，并**留在前向中**；它们的梯度被置零 [代码 core.py `_local_steps`]。
- **头部**由所有参与者共同训练，服务器按样本数做加权平均 [代码 core.py `weighted_head_mean`]。
- 弱端上传的只是 {Δθ_{jk} : k ∈ S_i^j} 和 Δθ_h，上传量占 LoRA 的 r_i/R [代码 model.py `upload_parameter_count`]。

### 3.4 要匹配的目标

受限训练改变了两件事：一是**本地轨迹**（只训练 r 个分量），二是**服务器收到的信息**（每个分量只有部分客户端贡献）。vref 只保留第二件：弱端完整训练，服务器只采用分给它的分量，再做 Hájek。vref 与 r8 一致（80.15 对 80.13 [判别]），说明第二件本身无害。所以本文的设计目标是：

> **在不改变上传内容和聚合规则的前提下，让受限弱端的本地轨迹（在被训练分量和头部上）与它完整训练时一致。** 这样，服务器端得到的就是 vref。

这个目标解释了为什么后面所有的修改都在本地，而服务器端只沿用 SCRA 已有的分配与聚合。

## 4. 机制推导：为什么受限训练会过冲

### 4.1 引理 1（Adam 第一步的尺度不变性）

每轮都新建 AdamW [代码 core.py `local_train`]。经过偏差修正后，第一步满足 m̂₁ = g₁，v̂₁ = g₁²，所以对每个标量参数 p：

  Δp₁ = −η · g_p / (|g_p| + ε) ≈ −η · sign(g_p)        （|g_p| ≫ ε 时）

在后续步骤中，Adam 的步长 |Δp_t| ≈ η · |m̂_t| / √v̂_t，大小由梯度符号的一致性（信噪比）决定，**与梯度本身的大小无关**。由此有两条推论：
1. 把某组参数的梯度乘以常数 c > 0，Adam 的轨迹不变（只差 ε 的影响）。
2. 每个被训练的标量参数每步都贡献大约 η 的位移，**不管其他参数已经把残差降掉了多少**。

### 4.2 命题 1（一阶降损对分量可加，受限训练的缺口）

在本轮起点 θ̄、本地第一个 batch 上，记

  G_k := ‖∇_{b_k} L‖₁ + ‖∇_{a_k} L‖₁        （分量 k 的一阶"降损能力"）
  G_h := ‖∇_{θ_h} L‖₁

由引理 1，第一步的一阶降损为（下式省略适配器下标 j，对 j 求和）：

  完整训练：  δL_full  = −η ( G_h + Σ_{k=1}^{R} G_k ) + O(η²)
  受限训练：  δL_restr = −η ( G_h + Σ_{k∈S} G_k ) + O(η²)

LoRA 部分完成的比例是

  ρ_S = Σ_{k∈S} G_k / Σ_{k=1}^{R} G_k

- 只要每个分量被分配的概率都是 r/R（覆盖均衡分配保证了这一点，见 §8.1），就有 **E_S[ρ_S] = r/R**。这不需要任何假设。
- 如果再假设各分量的 G_k 近似相等（**可互换假设 E**，见 §6.1），那么**对每个客户端都有 ρ_S ≈ r/R**。

这就是"每步的函数变化与被训练的分量数成正比"的精确含义：投影到降损方向上的函数变化，对分量是可加的。

**注（与 SGD 的关系）[推导]：** 在 SGD 下，Δθ_k = −η g_k，一阶降损是 −η Σ_{k∈S} ‖g_k‖₂²，同样对分量可加，所以 SGD 下受限训练同样会慢到约 r/R。Adam 特有的是另外两点：
1. 在 Adam 下，"把被训练分量的梯度乘以 R/r"完全无效（引理 1 的推论 1）。补偿只能放在前向里，或者放在学习率上。这两种做法一阶相同，但实测不等价，前向放大高 0.76pp（§7.2）[批量2]。
2. 补偿动力学由符号一致性驱动（§4.3）。

所以本文的论证**依赖 Adam**，指的是"哪种实现给出多大增益"依赖 Adam（§6.4），不是说受限训练变慢只在 Adam 下发生。

### 4.3 命题 2（本地补偿：缺口由头部和被训练分量补上）[推导 + 证据]

设一轮内的函数空间残差为 e_t。在 Adam 下，参数 p 在 T 步内的净位移约为

  |D_p| ≈ η · Σ_t |m̂_t| / √v̂_t ∝ 残差方向上梯度符号保持一致的步数

受限训练时，LoRA 每步只完成约 r/R 的降损，残差沿共识方向消失得更慢。头部和 r 个被训练分量的梯度符号因此保持一致更久，它们走得比完整训练时**更远**，直到把缺口补上。完整训练时，残差被很快降下去，梯度变成以噪声为主，Adam 的有效步长随之下降。

这个推理给出三个可检验的推论：
- **(a) 单个客户端的本地损失不必更高**：补偿基本补上了缺口。实测，D3 中弱端受限训练的本地平均损失为 0.6888 / 0.6055 / 0.5313，完整训练为 0.7030 / 0.6073 / 0.5502（第 20 / 60 / 120 轮快照）[D3]。受限训练的损失甚至略低。所以"残差持续"指的是 **LoRA 承担的那一部分降损不足**，不是本地损失降不下来。早期笔记里"损失降得慢"的说法应以此为准。
- **(b) 头部和被训练分量沿完整训练的方向走得更远**：单个弱端的头部步长中位数为 1.13 / 1.17 / 1.09，分量的范数比为 1.11 / 1.15 / 1.08，块余弦为 0.89 / 0.92 / 0.93 [D3]。
- **(c) 单个客户端的比值被噪声稀释，组均值才显出系统部分**：单个客户端的范数比只有约 1.1，组均值层面的放大却是 1.34–1.57（乘积空间）[D1]。这符合"系统性的补偿方向一致、在平均中叠加，各自的噪声相互抵消"。

### 4.4 命题 3（全局重复计入：拼接把补偿变成过冲）[推导]

把客户端 i 一轮的一阶函数变化分解为 F^full = F_h + Σ_{k=1}^{R} F_k（完整训练时）。受限训练时：

  头部：           F_h + C_h
  被训练分量 k∈S： F_k + C_k
  未训练分量 k∉S： 0

由 §4.3 的推论 (a)，本地补偿大致补上了缺口：

  C_h + Σ_{k∈S} C_k ≈ Σ_{k∉S} F_k =: Δ（缺口）

**服务器端：** 头部对所有参与者平均。每个分量 k 在**训练过它的客户端之间**平均（覆盖均衡保证每个分量都有人训练）。于是全局函数变化约为

  F̄^full + C̄_h + Σ_{k=1}^{R} C̄_k

完整训练时没有缺口。在全局模型中，所有 R 个分量都由某些客户端更新过，**缺口实际上已经被拼接补上了**。但头部的补偿 C̄_h 和每个分量的补偿 C̄_k 仍然被加了进去。这就是**重复计入**。

**上下界：** 若补偿全部落在头部，多出的部分约为 Δ。若全部落在被训练分量上，每个客户端的 r 个分量各多出约 Δ/r，拼接 R 个分量后多出约 (R/r)·Δ。所以 LoRA 沿共识方向的过冲倍数应当在 1 与 R/r = 4 之间，而且头部承担得越少，LoRA 的过冲越大。

**证据：**

| 推论 | 实测 | 来源 |
|---|---|---|
| 头部与 LoRA 都过冲，且 LoRA 的倍数 < R/r | L2 时 LoRA 沿 r8 的步长 1.70 / 1.55 / 1.60（Hájek：1.86 / 1.69 / 1.77），头部 1.93 / 1.64 / 1.67 | [D2] |
| 头部没有拼接，但它的补偿方向在客户端之间一致，所以也过冲 | 同上；头部在所有客户端之间直接平均 | [D2] |
| 两部分的影响超加性 | 只修 LoRA 或只修头部各损失约 0.3–1.3pp，都不修时损失 1.2–3.7pp | [D2]（research_two_directions §5 第 3 条） |
| 强端的完整更新会稀释过冲 | 第 20 轮时，无强端的轮次 L2 为 −15.3，有 2 个强端时为 −4.4 | [D2]（research_two_directions §5 第 4 条） |
| 不拼接就没有重复计入 | r2 同质（所有人训练同一组 2 个分量，全局模型就是 rank-2）平稳：波动 0.46 [批量] / 0.54 [判别]。前缀异构在 10% 强端时波动 1.19，强端增多后消失 [判别] | [判别]、[批量] |
| 过冲是均值偏移，不是方差 | 受限规则一步后准确率损失的均值是其标准差的 2–4 倍 | [D2]（research_two_directions §5 第 1 条） |

### 4.5 命题 4（压力转移）

由 §4.4：冻结头部（C_h = 0）后，全部补偿都落在分量上，LoRA 的过冲应当上升并接近上界 R/r。

**实测：** 弱端冻结头部（fh_hajek）时，LoRA 沿 r8 的步长为 2.49 / 2.34 / 2.27，一步后核心弱端的差值为 −15.95 / −10.91 / −5.93pp [D3]。过冲 2.3–2.5 倍，介于 1 和 4 之间，与上下界相符。

**含义：** 头部和分量分担的是**同一个**缺口。只修其中一处（服务器端收缩 LoRA、单独收缩头部、冻结头部），都只是把补偿挪到另一处。

### 4.6 机制排除了哪些修法

## 5. Method Specification

### 5.1 本地前向（弱端 i，α_i = R/r_i）

本轮开始时缓存 B̄、Ā。对每个适配器：

  W_j(θ) = W⁰_j + s · [ Σ_{k∉S} b̄_k ā_kᵀ + Σ_{k∈S} ( b̄_k ā_kᵀ + α_i (b_k a_kᵀ − b̄_k ā_kᵀ) ) ]
         = W⁰_j + s · [ B̄Ā + α_i Σ_{k∈S} (b_k a_kᵀ − b̄_k ā_kᵀ) ]

- 未训练分量以当前全局值留在前向，所以本地起点**就是**全局模型：一轮开始时增量为 0，前向与全局模型逐位相同（单元测试 `test_amplified_forward_value_and_gradient` 的第一条断言）[代码]。
- 只有本轮增量被放大，状态不被放大。§7.1 会说明，这正是它与 FSLoRA 的区别。
- 强端的 S = 全集，α = 1，公式退化为标准 LoRA。

**实现** [代码 model.py `LoRALinear.forward`]：

  update = B A x
  start  = B̄ Ā x
  output = W⁰x + s · ( update + (α−1) · (update − start).detach() )

前向的值等于上式。因为未训练分量的 b、a 在一轮内不动，所以 update − start 中未训练分量的项精确为 0，用完整的 B、A 计算与只对 S 求和完全相同。

### 5.2 梯度与上传

- **梯度**只经过未放大的 update 项。对被训练分量，得到的是放大后模型真实梯度的 1/α（单元测试中的断言：`g_detached * 4.0 == true grad`）[代码]。为什么这样做见 §6.4。
- **上传**未放大的原始增量 Δθ_k = θ_k − θ̄_k（k ∈ S）和 Δθ_h [代码 d0.py]。

**为什么上传原始增量** [推导]：放大之后，被训练分量的 Adam 位移与完整训练时同一分量的位移一致（D3 单端探针：块余弦 1.00 / 1.00 / 0.99，范数比 1.00，头部步长 1.00 [D3]）。放大因子只作用在本地前向里，**相当于让这个客户端"以为"其余 R − r 个分量也在按完整训练的速度前进**；在全局层面，这些分量确实由分到它们的其他客户端去更新。所以服务器对每个分量取贡献者的平均，再把 R 个分量拼起来，得到的就是完整训练更新的估计（§4.4 中的 C = 0）。如果上传 α·Δθ，全局更新会过冲 α 倍。

### 5.3 分配：覆盖均衡（沿用 SCRA）

- **同质 r** [代码 core.py `balanced_allocation`]：对每个适配器，把 r·n_w 个槽位尽量均匀地分到 R 个分量上，各分量的计数相差不超过 1，余数随机分给某些分量。再按随机顺序把槽位发给各个弱端，保证每个弱端拿到 r 个不同的分量。
- **异质 r_i** [代码 core.py `hetero_allocation`]：弱端按随机顺序，每人选当前贡献者最少的 r_i 个分量，平局随机打破。由随机顺序与平局的对称性，客户端 i 对任一分量的包含概率是 r_i/R。
- r·n_w < R 时，某些分量没有弱端贡献者，只由强端聚合（代码注释）。本设置中每轮约 9 个弱端，r = 1 时 9 ≥ 8，覆盖仍然成立 [配置]。

### 5.4 聚合：Hájek（沿用 SCRA）

对每个块 (j, k)，贡献者是全部强端加上 k ∈ S_i^j 的弱端：

  Δ̂_{jk} = Σ_{i∈贡献者} (p_i/π_{ijk}) Δθ^i_{jk} / Σ_{i∈贡献者} (p_i/π_{ijk})

- 强端：π = 1。
- 弱端同质 r：π_{jk} = c_{jk}/n_w（c 为计数，≈ r/R）。
- 弱端异质：π_i = r_i/R [代码 core.py `block_aggregates`]。
- 头部：所有参与者按样本数平均 [代码 core.py `weighted_head_mean`]。

### 5.5 算法框

```
算法：放大受限训练（ART）
输入：全量 rank R；弱端 rank r_i；乘子 s；本地步数 T；AdamW 超参数（weight_decay = 0）
初始化：A 用 Kaiming 均匀初始化，B = 0，分类头随机初始化

每轮 t = 1..T_rounds：
  1. 服务器抽取参与者 P_t，分成强端 𝒮_t 与弱端 𝒲_t
  2. 对每个适配器 j：覆盖均衡分配，得到 S_i^j（|S_i^j| = r_i）和计数 c_jk
       同质 r 用 balanced_allocation，异质 r_i 用 hetero_allocation
  3. 广播全局值 (B̄, Ā, θ̄_h) 和 S_i
  4. 强端 i ∈ 𝒮_t：标准本地训练（全部分量 + 头部），新建 AdamW，T 步，上传 ΔB, ΔA, Δθ_h
  5. 弱端 i ∈ 𝒲_t：
       α_i ← R / r_i；缓存 Ā, B̄
       新建 AdamW，参数为全部可训练参数；每步：
         前向：W_j = W⁰_j + s·[ B A x + (α_i − 1)·stopgrad(B A x − B̄ Ā x) ]
         反传；把 k ∉ S_i^j 的分量梯度置零；对全部梯度做范数裁剪（阈值 1.0）；AdamW 一步
       关闭放大；上传原始增量 {Δb_jk, Δa_jk : k ∈ S_i^j} 和 Δθ_h
  6. 服务器：
       对每个块 (j,k)：Hájek，强端 π = 1，弱端 π = c_jk/n_w 或 r_i/R
       没有贡献者的块保持不变
       头部：按样本数加权平均
  7. 更新全局模型
```

### 5.6 超参数与保持不变的部分

- **没有新的可调超参数**：α 由 R/r_i 决定。批量消融只测了 α ∈ {2, 4, 8}（§6.6）。
- **与基线 L2 / hajek 相同、保持不变：** 模型、LoRA 的放置、乘子 s、AdamW 的全部超参数（包括头部学习率）、本地步数、上传内容与字节数、强端的训练、评估方式。

## 6. α = R/r 的推导

### 6.1 假设

- **U（均匀包含）：** 对每个弱端 i、每个适配器 j、每个分量 k，P(k ∈ S_i^j) = r_i/R。覆盖均衡分配保证这一点（§5.3）。
- **E（一阶可互换）：** 在同一个适配器内，各分量的一阶降损能力 G_k 近似相等。
  - 冷启动时 B = 0，∇_{a_k} L = 0，G_k = ‖∇_{b_k} L‖₁ 只依赖 a_k。a_k 是独立同分布的随机初始化，所以 G_k 在分布上可互换。
  - 训练推进后，b_k 积累了不同的方向，E 可能逐渐被破坏（§6.5）。
- **O（Adam）：** 优化器的步长对梯度的尺度不变（引理 1），且梯度远大于 ε。
- **W（无权重衰减）：** AdamW 的 weight_decay = 0。若 > 0，未训练分量虽然梯度为 0，仍会被衰减，前向里的"冻结"就不再成立（§11）。

### 6.2 命题 5（第一步、一阶）

放大后，模型在起点处对被训练分量的真实梯度是 α∇_k L。detach 后，优化器看到的是 ∇_k L。由引理 1，第一步 Δθ_k = −η sign(∇_k L)，和不放大时相同。但函数变化乘了 α，所以

  δL_amp = −η ( G_h + α Σ_{k∈S} G_k ) + O(η²)

要让 LoRA 部分与完整训练一致，需要 α Σ_{k∈S} G_k = Σ_{k=1}^{R} G_k，即每个客户端的理想值是

  α*_S = Σ_{k=1}^{R} G_k / Σ_{k∈S} G_k = 1/ρ_S

- **仅在假设 U 下：** E_S[α Σ_{k∈S} G_k] = α·(r/R)·Σ_k G_k。所以 **α = R/r 是唯一能使期望降损与完整训练相同的常数**。注意，由 Jensen 不等式，E[α*_S] ≥ R/r。R/r 是对降损无偏的选择，不是对 α*_S 无偏的估计。
- **再加上假设 E：** 对每个客户端都有 α*_S ≈ R/r，客户端之间的偏差也随之消失。
- **头部这一项在三种训练方式中都一样**（都是 −ηG_h）。头部的差异只在第二步之后通过残差出现（§4.3）。所以只要补上 LoRA 的缺口，头部就自动回到完整训练的轨迹，**不需要单独修正头部**。这是方法中没有任何头部专用组件的原因。

### 6.3 多步的延伸 [推导 + 证据]

如果第 t 步时，放大训练的函数状态与完整训练只差 O(η²)，那么第 t+1 步时，两者看到的残差和头部梯度也只差 O(η²)，被训练分量的 G_k 与完整训练时的同一分量一致，于是第 t+1 步的一阶降损再次匹配。误差逐步累积，来源主要是二阶交叉项 α Δb_k Δa_kᵀ（§7.2）和可互换假设的偏离。

这只是归纳式的论证，不是定理。实测：一轮 20 步之后，单端块余弦 0.99–1.00，范数比 1.00，头部步长 1.00；本地损失 0.7038 / 0.6072 / 0.5495，完整训练为 0.7030 / 0.6073 / 0.5502，相差 ≤ 0.007 [D3]。位移与完整训练的余弦为 0.992–0.997，不是逐位相同 [D3 核查]。

### 6.4 对优化器的依赖：四种实现的增益 [推导]

设一种实现在前向中给分量的增量乘 α_f，在梯度上乘 α_g（相对于未放大训练的梯度）。每个被训练分量每步的函数变化增益 Γ 为：

  Adam：Γ = α_f        （α_g 被尺度不变性吸收）
  SGD： Γ = α_f · α_g

要补上缺口，需要 Γ = R/r。

| 实现 | α_f | α_g | Adam 下的 Γ | SGD 下的 Γ | 备注 |
|---|---|---|---|---|---|
| **本文（放大前向 + detach）** | R/r | 1 | **R/r** | **R/r** | 两种优化器下都正确；梯度裁剪看到的尺度与 L2 相同 |
| 放大前向，不 detach（真实梯度） | R/r | R/r | R/r | (R/r)² | 在 SGD 下要改用 α = √(R/r) 才正确。在 Adam 下与本文只差 ε 的影响：小模型、B = 0 时走一步，eps = 1e-8 相对差 12.4%，1e-10 为 1.1%，与梯度裁剪无关 [审查 §2、§10]；但多轮训练中只差 −0.11pp [批量2 A1b] |
| 只放大梯度 × R/r | 1 | R/r | **1（无效）** | R/r | 在 Adam 下什么也没改变 |
| 学习率 × R/r（+ 服务器 ÷ R/r） | — | — | R/r | R/r | **只是一阶增益相同**，二阶项和 Adam 状态不同（§7.2）；实测比本文低 0.76pp [批量2 A2] |
| FSLoRA（按论文公式） | R/r | R/r | R/r | (R/r)² | 论文用 SGD，靠零填充平均在期望上抵回 [文献 §4.1]；在 Adam 下零填充不再被抵回（§7.1，−2.62pp [批量2 A1c]） |

**这张表的适用范围：** Γ 只描述第一步的一阶增益。它能排除"只放大梯度"这类在 Adam 下无效的实现，但**不能**用来判定两种 Γ 相同的实现在多轮中等价。阶段 A2 的结果就是反例（§7.2）。

**SGD 下的对应结论** [推导，未测]：若用 SGD，本文的实现仍应取 α = R/r，因为 detach 使 α_g = 1。若不 detach，应取 α = √(R/r)。补偿动力学的形式也会不同：SGD 下净位移 ∝ ∫ ‖残差‖ dt，由幅度驱动；Adam 下由符号一致性驱动。缺口本身仍然存在（§4.2 注）。

**detach 在 Adam 下的实际作用：** 理想条件下（eps → 0、不裁剪）方向上没有区别；实际训练中的差别也很小（−0.11pp，95% 区间 [−0.32, +0.10]，[批量2 A1b]）。它带来两点好处：
1. 梯度范数与未放大训练处在同一尺度，裁剪阈值 1.0 的作用与 L2 相同。裁剪是对头部与 LoRA 的联合范数做的；不 detach 时，LoRA 的梯度会大 α 倍，改变裁剪对头部的影响。
2. ε 相对于梯度的比例与 L2 相同。

### 6.5 假设何时失效

| 情形 | 失效的假设 | 预期后果 [推导] | 诊断 |
|---|---|---|---|
| **分量专门化**：训练后期，各分量学到了不同的功能，‖b_k‖、‖a_k‖ 差异变大 | E | α*_S 在客户端之间离散。在 U 下期望仍然正确，但单个客户端会放大不足或过度 | 在快照上计算第一步的梯度 L1 比 α̂_S = Σ_k G_k / Σ_{k∈S} G_k，看它的分布是否集中在 R/r 附近。D3 第 120 轮的单端探针仍是 1.00 [D3]，说明在本设置的 150 轮内 E 没有明显失效 |
| **SGD 代替 Adam** | O | 本文的实现仍然取 α = R/r（§6.4），但 "放大梯度" 和 "放大前向" 不再等价，FSLoRA 式的实现会过度放大 | 没有测过。若要声称适用于 SGD，需要单独实验 |
| **按层 / 按深度限制**（只训练顶部若干层） | E（层与层不可互换），以及"冻结部分留在前向"的结构 | 各层的 G 差别很大，底层冻结还改变了反传，α = L/l 没有依据 | 若推广，α 应按第一步实测的降损比 α̂ 取，而不是按计数取（未测的扩展，不纳入本方法） |
| **AdamW 的 weight_decay > 0** | W | 未训练分量被衰减，起点不再是全局模型 | 代码中要么保持 wd = 0，要么把未训练分量从衰减中排除 |
| **梯度接近 ε**（极小的学习信号） | O | 尺度不变性被破坏 | detach 使这一点与 L2 相同，不额外恶化 |
| **r·n_w < R** | U（部分分量的包含概率为 0） | 这些分量只由强端更新，见 §8.1 | 每轮记录无弱端贡献者的块数 |

### 6.6 关于 α 的证据

| α（R = 8，r = 2） | 核心弱端 | 与 amp 之差 | 波动 | 来源 |
|---|---:|---:|---:|---|
| 2（放大不足，ρ·α = 1/2） | 79.47 | −0.58 | **0.97** | [批量] |
| **4 = R/r** | 80.05 | — | 0.37 | [批量] |
| 8（放大过度，ρ·α = 2） | 79.91 | −0.14 | 0.36 | [批量] |

**不对称的解释** [推导，单 seed，未单独检验]：
- 放大不足时，缺口只补了一半，补偿与拼接过冲机制仍然存在，所以摆动又回来了。
- 放大过度时，本地残差降得比完整训练还快，被训练分量的梯度很快以噪声为主，Adam 的有效步长随之下降。于是原始增量偏小，全局更新略微不足，但不会过冲。
- 也就是说，放大过度会自我限制，放大不足不会。
- α = 8 的 −0.14 在单 seed 噪声（约 0.2–0.4pp [批量]）以内，所以**不能**据此声称 R/r 是最优值，只能说它在测过的三个值中最好，并且结果对放大过度不敏感。

## 7. 与已有工作的精确关系

### 7.1 与 FSLoRA：只差状态 sketch 误差 ξ_S

FSLoRA 的本地前向是 [文献 §4.1]：

  W_FS = W⁰ + s · α Σ_{k∈S} b_k a_kᵀ        （未选分量不参与前向）

本文的前向是 W_ours = W⁰ + s·[ B̄Ā + α Σ_{k∈S}(b_k a_kᵀ − b̄_k ā_kᵀ) ]。两者相减：

  W_FS − W_ours = s · ξ_S，  ξ_S := α Σ_{k∈S} b̄_k ā_kᵀ − Σ_{k=1}^{R} b̄_k ā_kᵀ

ξ_S 只依赖本轮起点的状态，在一轮内是常数。它有以下性质 [推导；与文献 §1.1 一致]：
1. **冷启动时 ξ_S = 0**（B̄ = 0），两者的前向值完全相同。但本地更新只在 Adam eps → 0 的极限下才完全相同：eps = 1e-8 时，小模型一步相差 12.4% [审查 §2、§10]。批量 2 的 fslora_st 对照（前向同 FSLoRA，梯度路径同 amp）去掉了这一差别。单元测试确认，冷启动时 fslora_st 与 amp 的整个本地训练一致 [审查 §10]。
2. 在假设 U 下 E_S[ξ_S] = 0，但对单个客户端不为 0；它的大小随 ‖B̄‖ 的积累而增大。
3. 两者的**增量部分**完全相同（都乘 α）。在 Adam 下，FSLoRA 梯度中多出的 α 被尺度不变性吸收（§6.4），所以本地函数变化的速度相同。这只是近似，梯度量级接近 eps 时不成立（见第 1 条）。多轮训练中这一差别只有 −0.11pp（A1b，见下）。
4. 因此，唯一的本地差别是：FSLoRA 的客户端从 W⁰ + s(B̄Ā + ξ_S) 出发，而不是从全局模型出发。它在本地要先"修正" ξ_S，这部分修正会混进上传的增量；头部也是在一个被扰动的主干上训练的。在 U 下期望为零，**表现为额外的客户端间方差，大小随训练推进而增大。**

**聚合也不同：** FSLoRA 对所有 N 个参与者做零填充平均（1/N），不按贡献者数归一化。按论文的 SGD 写法，梯度中的 α 在期望上抵回这一缩小。但在 **Adam 下**，原始增量没有被 α 放大（§5.2），零填充平均会把弱端对每个分量的贡献缩小约 r/R 倍。强端的相对份额被抬高，与拥有者平均类似（§8.2），全局 LoRA 的步长也变小 [推导]。**FSLoRA 的无偏性论证建立在 SGD 上，在 Adam 下不成立。**

**事先的推导预测**（本稿初版写下，批量 2 出结果之前）：
- (i) A1-Hájek 与 amp 在第 1–50 轮应当几乎相同，差别若有，在中后期逐渐显现，大小未知；
- (ii) A1-零填充应明显差于 A1-Hájek，所以判定"不对状态做 sketch 是否有价值"时，应当以同聚合、同梯度路径的对照为准。

### 7.2 与"学习率 × α + 服务器 ÷ α"：一阶相同，实测不等价

把分量的增量展开：

  b a ᵀ − b̄ ā ᵀ = Δb āᵀ + b̄ Δaᵀ + Δb Δaᵀ

- **本文：** 前向增量 = α(Δb āᵀ + b̄ Δaᵀ) + **α** Δb Δaᵀ。
- **学习率 × α（阶段 A2）：** 参数实际走了 αΔb、αΔa，前向增量 = α(Δb āᵀ + b̄ Δaᵀ) + **α²** Δb Δaᵀ。服务器 ÷α 之后，全局拿到的是 b̄ + Δb、ā + Δa，与本文的上传相同。

所以两者在一阶上相同，差别只在本地轨迹的二阶交叉项（系数 α 对 α²）。另外，A2 中 b 的梯度是在 ā + αΔa 处计算的，本文是在 ā + Δa 处计算的，这也是二阶差别。

**交叉项的大小（最坏情形，由超参数估计，未实测）[推导]：** 相对大小约为 ‖Δa_k‖/‖ā_k‖。
- 一轮内，每个坐标的 Adam 位移不超过约 Tη = 20 × 2e-4 = 4e-3，所以 ‖Δa_k‖ ≤ 4e-3 × √768 ≈ 0.11。
- 初始化时 ‖a_k‖ ≈ √(768 · (1/768)/3) ≈ 0.58。
- 所以最坏情形下，本文约为 0.19，A2 约为 0.77。
- 这个上界很松：它假设 20 步的符号全部相同；而且冷启动时 b = 0，所以 a 在第一步并不移动。

所以推导**不能排除** A2 与 amp 有差别（本稿初版没有预先断定结果）。

**阶段 A2 的结果**（3 seed 配对 [批量2]）：

| | 每个 seed（晚期） | 均值 | 95% 区间 | 早期 / 中期 |
|---|---|---:|---|---|
| amp − lrcomp | +0.70 / +1.00 / +0.59 | **+0.76** | [+0.23, +1.30] | +1.18 / +0.79 |

- lrcomp（A2）晚期为 79.36 ± 0.05，amp 为 80.12 ± 0.17。波动分别为 0.41 和 0.35 [批量2]。
- 路线图的判读（相差 < 0.3pp 时视为等价）**不成立**。按批量 2 事先写定的判读，"前向形式本身重要，报告哪一方更好"：**前向放大更好**。
- 差距在前期更大：原报告给出第 10 轮为 +1.2 到 +2.0 [research_two_directions §8]，早期窗口均值 +1.18 [批量2]。

**对本节原有论证的修正：** "一阶相同"仍然成立，但**它不足以推出两者在多轮中等价**。§6.4 的增益表只描述第一步的一阶行为，不能用来论证 A2 ≈ amp。

**原因：未验证，只作为观察报告。** 候选解释有两个：
1. 二阶交叉项的系数 α² 对 α（上文）。在冷启动阶段，ΔbΔa 相对 Δb ā 的大小由 Δa 决定，可能与"前期差距更大"有关。
2. Adam 状态在更大步长下的行为不同：A2 中被训练分量在参数空间里走了 α 倍的路程，梯度在 ā + αΔa、b̄ + αΔb 处计算，Adam 的一阶、二阶矩沿另一条轨迹累积。

区分两者的诊断（未做）：在 D3 式的单步探针中，比较 amp 与 lrcomp 的单端块余弦、范数比、头部步长，以及交叉项的实测大小 ‖ΔbΔaᵀ‖/‖Δb āᵀ + b̄Δaᵀ‖。在这之前，论文中只写"实测前向放大优于调学习率 0.76pp"，不写原因。

**对方法表述的影响：** 方法应表述为"**前向放大**"本身，而不只是"使本地进展与完整训练匹配"。后一种说法会把 A2 也包括进去，而 A2 实测更差。

**放大前向在工程上的好处**（与 A2 的结果无关）：
- 不改动优化器的超参数和状态，头部学习率天然不变。
- 上传天然处在完整训练的尺度上，服务器端不需要知道 α。
- α = 1 时与受限 Hájek 逐位相同（单元测试 `amp with alpha 1 == plain restricted Hajek, bitwise`）[代码]。

**为什么单独调学习率不行：** 不在服务器端 ÷α 的话，上传的位移大 α 倍。判别实验中弱端学习率 × 0.6 的失败（§4.6，[判别]）也说明，学习率和收缩不能互相替代 [文献 §4.5]。

### 7.4 不可约的差别

1. **只对增量做 sketch，不对状态做 sketch**：本地起点就是全局模型（与 FSLoRA 相差 ξ_S）。
2. **动机与诊断**：Adam 下一阶降损的缺口 → 本地补偿 → 拼接后的重复计入（§4）。这条机制链以及支撑它的测量（D2 / D3）没有在文献中找到 [文献 §5]。

## 8. 覆盖均衡分配与 Hájek 各自修正什么

由 §5.2，放大之后，弱端对分量 k 的原始增量是它完整训练时这个分量增量的一个样本。服务器要估计的是本轮参与者的完整训练更新的加权均值：

  目标：Δ*_{jk} = Σ_{i∈P_t} p_i Δθ^{i,full}_{jk} / Σ_{i∈P_t} p_i

这是一个按设计抽样的估计问题，需要两个条件。

### 8.1 正性：覆盖均衡分配

**要求：** 每个分量对弱端的包含概率 π > 0。π = 0 时，不存在任何能恢复弱端贡献的估计量。

**前缀分配为什么失败** [推导]：所有弱端都训练 0..r−1，第 r..R−1 个分量只由强端更新（每轮约 1 个强端，有的轮次没有）。放大让每个弱端在本地"以为"其余分量在按完整训练的速度前进，但在全局，这些分量实际上只代表强端的数据。所以弱端数据对 LoRA 的影响只剩约 r/R，其余部分偏向强端的领域。

**实测：** 前缀分配代替覆盖均衡：−1.55pp，closure 0.32，波动 0.48 [批量]。

**覆盖均衡还提供两点：**
- 包含概率均匀为 r_i/R。这是 α = R/r 在期望上正确的前提（假设 U，§6.2）。
- 每轮内是不放回地分配，比独立随机选择（Fed-PLoRA 的做法）的计数波动小 [代码 core.py 注释]。

### 8.2 包含概率：Hájek

**要求：** 按 1/π 对弱端加权，恢复强端与弱端在总体中的比例。

**拥有者平均的问题** [推导，按等样本量近似]：每个块的贡献者是全部强端加上约 r/R 的弱端。拥有者平均下，强端的份额约为 n_s/(n_s + (r/R)·n_w)，而总体份额是 n_s/(n_s + n_w)。按每轮约 1 个强端、9 个弱端、r/R = 1/4 计算，约为 0.31 对 0.10，强端被高估约 3 倍。强端集中在 government、travel 两个领域 [配置]，所以核心弱端受损。

**实测：** 拥有者平均代替 Hájek：−0.45pp，closure 0.78 [批量]。这是单 seed 结果，只是刚好超过 0.3pp 的判据。

**Hájek 只有在放大之后才有帮助（自洽性检验）：**
- 不放大时，弱端的增量里含有补偿 C（§4.3）。Hájek 抬高弱端的权重，也就抬高了补偿的权重，所以会更差。D2 中 Hájek 比拥有者平均更差：−12.09 / −8.29 / −4.45 对 −9.77 / −6.71 / −3.39 [D2]。
- 放大后补偿消失，弱端的增量与强端处在同一尺度，Hájek 的总体加权就成了正确的估计量。
- 这与 D1 的观察一致：修正过冲之后，Hájek 重新优于拥有者平均 [D1]。所以 Hájek 不是独立叠加上去的组件，它依赖放大带来的尺度一致。

**零填充平均：Adam 下的第三种错误加权。** 零填充对每个块用所有参与者的权重做分母，未训练的客户端计为 0 [代码 core.py `block_aggregates` 的 `zerofill`]。
- 推导 [推导]：弱端对每个分量的有效权重约为应有值的 r/R；强端的相对份额被抬高；整体步长也缩小。只有当原始增量本身被放大 R/r 倍时，这一缩小才会在期望上抵回，例如 SGD 下 FSLoRA 梯度中的 α（§6.4）。放大前向加 detach，或者 Adam 下的任何实现，都不满足这一条件。
- 实测：同样是 FSLoRA 前向、覆盖均衡分配，零填充比 Hájek 低 2.62pp（3 seed 同向，区间 [+2.30, +2.94]），早期差距 +6.89pp，波动 0.49 对 0.32 [批量2 A1c]。
- 同一机制也与 FLASC 式（完整训练 + 零填充）低于 vref（完整训练 + Hájek）相符：79.33 对 80.17 [批量2]。但这两者还差上传方式（Top-K 对按分量分配），不是单因素对照。

| 聚合（放大或完整训练之后） | 弱端的有效权重 | 实测 |
|---|---|---|
| Hájek | 正确（1/π 校正） | amp 80.12 [批量]；fslora_hajek 79.80 [批量2] |
| 拥有者平均 | 每个块中强端被高估约 3 倍（等样本量近似） | −0.45pp（单 seed）[批量] |
| 零填充 | 约 r/R，整体步长也缩小 | −2.62pp（3 seed）[批量2 A1c] |

### 8.3 头部

所有参与者都训练头部，π = 1，按样本数平均就已经是总体加权，不需要修正。放大之后头部步长为 1.00 [D3]，说明头部也不需要单独的系数。

## 16. Paper Method Bridge

**方法章节的结构建议：**
1. 设定：异构 rank 联邦 LoRA，以及受限训练的约束（§3）。
2. 诊断性的观察：差距不在通信（vref、budget8）；受限更新沿共识方向过冲，头部同样如此；冻结头部会把压力转移给分量（D2、D3）。
3. 机制：Adam 下一阶降损对分量可加 → 本地缺口 → 补偿 → 拼接后重复计入（命题 1–4）。
4. 方法：放大本轮增量（命题 5 给出 α = R/r），上传原始增量，覆盖均衡分配加 Hájek（§5、§8）。算法框用 §5.5。
5. 定位对照：状态 sketch（A1a）、聚合（A1c）、调学习率（A2），以及外部基线（§7.1、§7.2）。
6. 讨论：假设与适用范围（§6.5）；A2 差距的原因尚未验证。

**收益的构成**（核心弱端晚期，3 seed 配对；分解由本文用 [批量] 和 [批量2] 的逐 seed 数字计算）：

| 步骤 | 每个 seed | 均值 | 含义 |
|---|---|---:|---|
| L2 → fslora_st | +1.99 / +2.47 / +1.07 | +1.84 | 放大（FSLoRA 式，对状态也做 sketch），同时从拥有者平均换成 Hájek |
| fslora_st → amp | +0.35 / +0.56 / +0.36 | +0.42 | 只放大增量、不对状态做 sketch（A1a） |
| **L2 → amp（合计）** | +2.33 / +3.04 / +1.43 | **+2.27** | — |

- research_two_directions §8 中"主要收益约 2.3pp 来自放大本身"，指的是这一合计。其中约 0.42pp 来自不对状态做 sketch，其余约 1.8pp 来自"放大 + Hájek"。
- 第一步不能再拆开：没有跑过多轮的"受限训练 + Hájek、不放大"。D2 的单步结果显示，不放大时 Hájek 比拥有者平均更差（§8.2），所以这 1.8pp 不应理解为 Hájek 的贡献。
- 前向放大相对调学习率另有 +0.76pp（A2），这是另一个维度的比较，不在上表的链条中。

**需要陈述的假设：** U、E、O、W（§6.1），以及"存在共同训练的头部"这一设定。

**可以这样写**（沿用 [文献 §6.3]，并按本文 §4.3 修正"残差"的含义）：

> 在 Adam 下，只训练 R 个 LoRA 分量中的 r 个时，每步的一阶降损约为完整训练的 r/R。缺口由共同训练的分类头和被训练分量以更大的位移补上；服务器把不同客户端训练的分量拼接起来之后，这些补偿沿共识方向重复计入，表现为过冲。我们让冻结分量以当前全局值留在前向，只把被训练分量的本轮增量放大 R/r 倍，上传未放大的增量，并按覆盖做 Hájek 聚合。与 FSLoRA 不同，我们不对当前状态做 sketch，所以每个客户端都从全局模型出发；两者只在适配器为 0 时一致。在相同的分配、聚合和梯度路径下，不对状态做 sketch 带来 0.42pp 的提升。前向放大也比一阶等价的"调学习率 + 服务器端缩回"高 0.76pp。我们还发现，FSLoRA 的零填充平均在 Adam 下会把弱端更新低估约 r/R：同样的前向，换成 Hájek 高 2.62pp。

（以上数字均来自 [批量2]，3 seed 配对。）

**不能这样写：**
- "首次在部分训练中放大更新"或"首次让冻结部分留在前向"[文献 §6.3]。
- "无偏"或"有收敛保证"。
- "等价于完整训练"（余弦 0.992–0.997）。
- "节省显存"（RoBERTa 规模下是 1558 对 1557 MiB）。
- "α = R/r 是最优的"（只测了三个值，单 seed，α = 8 的差别在噪声以内）。
- "Hájek 必不可少"（单 seed，−0.45pp，刚过判据）。
- "适用于 SGD / 按层限制 / 没有分类头的模型"（都没有测过）。
- 不夸大"只放大增量"的作用：它只带来 +0.42pp，主要收益来自放大本身（见上方的收益构成）。
- 不写"放大前向等价于调学习率"（实测相差 0.76pp），也不写这一差距的原因（未验证，§7.2）。
- 不把外部定位（+2.95 / +2.96 / +0.79）当作机制证据：这些比较同时改变了多个因素。
- 不写"FSLoRA 是错的"：零填充在 FSLoRA 原论文的 SGD 设定下有它的道理，只是在 Adam 下不成立。
- 不写"受限训练的本地损失降得慢"：实测本地损失并不更高（§4.3(a)）。

## 阶段 A：定位对照（GPU，约 3–4 GPU 小时）

目的：回答审稿人最可能提的三个问题。

| # | 对照 | 回答的问题 | seed | 事先写定的判读 |
|---|---|---|---|---|
| A1 | **FSLoRA 式前向**（按论文公式：被选分量的整个乘积乘 R/r，未选分量不参与前向），分别配零填充 1/N 平均和 Hájek | "只放大增量、不对状态做 sketch"是否有实际价值 | 3 | 若低于 amp ≥ 0.3pp（3 seed 均值），主张成立；否则主张缩小为"对 FSLoRA 式放大在 Adam 下的新解释与诊断" |
| A2 | **学习率 × α + 服务器 ÷ α**（受限分量的 Adam 学习率 ×4，头部不变；上传位移 ÷4） | 放大前向是否只是"调学习率"的另一种写法 | 3 | 两者相差 < 0.3pp 时，把方法表述为"使本地进展与完整训练匹配"，实现形式作为细节 |
| A3 | **Fed-PLoRA 式**：随机选分量 + 拥有者平均，不放大 | 最直接的已发表基线 | 3 | — |
| A4 | **FLASC**：本地完整训练，同等字节的 Top-K 稀疏上传，零计入平均 | 通信受限方向的已发表基线（对应 vref） | 3 | — |

- 按 FSLoRA 的预测，冷启动时 A1 与 amp 相同，差别只会在中后期出现，所以**结果要分阶段报告**（第 1–50 / 51–100 / 101–150 轮）。
- 汇总沿用 `run.py batchreport` 的形式，另写一个 `batch2report`。

## 阶段 B：方法设计文档（不用 GPU，与阶段 A 并行）

满足"先有完整、自洽的推导"这一要求，也是论文方法章节的底稿。

1. 问题形式化：异构 rank 联邦 LoRA 的目标；弱端只训练 r_i 个分量的约束。
2. 机制：在 Adam 下，每步的参数步长与梯度大小无关，函数变化 ∝ 训练的分量数 → 残差持续存在 → 共同训练的头部和分量过冲；拼接后进一步叠加。
3. α = R/r 的推导，以及它依赖的假设（一阶意义下分量可互换），说明这个假设何时会失效。
4. 与 FSLoRA 的精确关系：两者的前向只差状态 sketch 误差 ξ_S，冷启动时为 0。
5. 覆盖均衡分配与 Hájek 各自修正什么（正性 / 包含概率）。
6. 算法框、复杂度（额外开销：每个适配器多一次秩 r 的矩阵乘）。
7. 每个预测与已有证据的对照表：D2、D3、批量验证、A1–A2。

## 阶段 C：资源动机与通用性（先纸面，后实验）

**C1 纸面核算（不用 GPU）：** 在 1–3B 模型、全线性层 LoRA、R = 64 / r = 8 等设定下，计算受限训练节省的部分（LoRA 梯度与 Adam 状态 ∝ r/R，上传 ∝ r/R），以及不变的部分（激活、主干）。据此决定论文的卖点：
- 节省足以支撑"弱端训练不起完整 rank"的说法 → 保留"计算受限"的叙事；
- 不够 → 卖点改为"训练状态和通信同时降到 r/R，且精度无损"，并如实说明节省的规模。

**C2 大模型通用性实验（GPU，最大的一块工作）：** 题目是"联邦大模型"，而 RoBERTa-base 不算大，而且它有一个从零训练的分类头。在一个 0.5–1.5B 的解码器模型上（例如 Qwen2.5-0.5B，LoRA，没有新的分类头）做一组精简的对照：r8、L2、vref、amp，每组 1–3 个 seed。
- **事先写定的预测：** 没有可训练的头部时，压力全部落在 LoRA 分量上（类似 D3 中冻结头部的情形，过冲 2.3 倍），所以 L2 的差距应当**仍然存在甚至更大**，而 amp 应当仍能追平。
- 如果没有可测的差距：在论文中如实说明，方法的适用范围是"有共同训练参数（如分类头）或差距可测的设定"。
- 需要新写数据、模型和评测的流水线，开始前先单独写一份实验设计。

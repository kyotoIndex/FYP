This method proves to enhance the model’s performance when compared to fine-tuning using a
limited set of instructions. Additionally, we introduce Shepherd, a GitHub repository designed for
exploring federated fine-tuning of LLMs using heterogeneous instructions across diverse categories.
The framework is user-friendly, adaptable, and scalable to accommodate large datasets and models.

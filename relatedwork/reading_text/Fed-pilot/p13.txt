A.3 Dynamic and Static Activations: An Example for ViT-base with LoRA module
In the previous sections, we defined dynamic and static activations. Here, we provide a real example using the ViT-base [9] model, which
consists of 12 transformer blocks with LoRA modules added to the attention layers. Figure 7 illustrates the activation memory usage in a
transformer block of ViT-base, where only the LoRA modules are trainable.
Among different operations, GELU, MatMul, Softmax, and LayerNorm involve static activations, as summarized in Table 11. Notably,
MatMul and Softmax share the same activations—Softmax stores its output during the forward pass for reuse in backward computations,
while MatMul requires its input for backpropagation. Since Softmax’s output serves as MatMul’s input during the forward pass, both
operations rely on the same activations.

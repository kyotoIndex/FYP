Anonymous code release.The core implementation of FedSAIL is available at
https://anonymous.4open.science/r/FedSAIL-4A7C/.
The repository implements input-moment estimation and shrinkage, compact spectral messages, server-side
subspace aggregation, the local action residual penalty, layer selection, and communication accounting. Syn-
thetic CPU tests check these components against dense reference computations, including reparameterization
invariance and penalty gradients. Experimental settings and evaluation conventions are documented in the
preceding appendices.
Installation and verification.The standalone package requires Python 3.10 or later and PyTorch. From the
repository root, the following commands install the package and run its numerical tests without downloading
models or datasets:
python -m pip install -e ".[test]"
PYTHONDONTWRITEBYTECODE=1 python -m pytest -p no:cacheprovider

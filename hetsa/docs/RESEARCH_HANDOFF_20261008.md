# HetSA 研究交接（2026-10-08）

## 当前问题

先用完整配对实验回答：异构深度与部分参与下，服务器替换共享 A 是否损伤客户端私人 B 的预测；若损伤存在，本地低秩 ridge 适配是否能减轻损伤并改善相同训练预算下的最终结果。低频共享 A、固定 A 与完全本地对照用于判断收益来自共享、更新频率还是私人适配。

## 已有证据

已完成 AG_NEWS/BERT-base 五种子确认：HetSA 本地留出 94.11%，相对同深度 A+B 聚合 +11.88 pp，五个种子均超过预设 +1 pp 门槛。相对全深度 FedSA −0.17 pp；已有时间/FP32 载荷代理减少约 42.5% / 37.1%。A-only 服务器 25.48%。完整原始表与复算脚本在本目录。

共享 A/本地 B 来自 FedSA-LoRA，异构层预算有 Fed-HeLLo、LEGEND 等先例；现在把创新问题落到异构深度、部分参与与私人 B 的兼容性上。论文阅读报告、PDF、作者 TeX 和具体对照在 ../../relatedwork/。

## 新矩阵的固定方法

| 方法 | A | B | 头 | 作用 |
|---|---|---|---|---|
| hetsa | 每轮共享更新 | 本地保留 | 共享 | 主对照 |
| repair_half | 每轮共享更新 | 本地 ridge，强度 .5 | 共享 | 半量适配 |
| repair_full | 每轮共享更新 | 本地 ridge，强度 1 | 共享 | 全量适配 |
| slow_a | 前 3 轮及每 3 轮共享更新 | 本地保留 | 共享 | 共享频率控制 |
| local_only | 完全本地 | 完全本地 | 完全本地 | 去掉共享 |
| fixed_a_local_b | 固定共同初始化 | 本地训练 | 共享 | 冻结 A 控制 |

适配目标：min_B ||B A_new − B_old A_old||²_F + λ||B − B_old||²_F，λ = 1e−3 trace(A_new A_new^T)/r + 1e−8。实现只解 r×r 系统，不构造完整稠密权重。强度与频率在运行前固定。

同一客户端测替换 A 前、替换后、修复后的 loss/accuracy；三者使用相同的聚合分类头。记录资源档位、遗漏轮次、client/round 配对训练 RNG、实测串行训练/适配时间、显存与 FP32 参数载荷。端点为第 26–30 轮本地留出均值；共同均衡测试子集有 256 条。

## 怎样判定

先看 A 替换前后的配对损伤，再看适配是否恢复，最后看完整五种子端点和实际代价。若基线没有损伤，则不将适配描述为解决了已证实的问题。展示所有六种方法，以种子计算配对区间。现有本机快照只有 seed 1201 原版 HetSA 30 轮，不包含六方法配对结论。

GitHub 已合并 PR #2–#4，研究的是另一套共享模型、SST-2 与固定通信额度问题。可用作历史机制证据；本次主线由这里的协议与 AG_NEWS 配对实验推进。
